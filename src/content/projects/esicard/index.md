Led the technical development of a **multifunctional student ID card** for the
Lichtenbergschule while I was a student there. We created tools for the card
issuance process and developed interfaces for the student and library databases.
The system remains in active use today.

Featured in a [BCG "business@school" article](https://www.businessatschool.de/de/aktuelles/detail/schuelerausweis-lichtenbergschule-darmstadt).
